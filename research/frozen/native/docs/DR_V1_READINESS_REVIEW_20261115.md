# 第一版可用 DR solution：獨立 readiness 審查

## 使用者回覆後的目前基準（2026-11-15）

本節為主agent記錄使用者在審查後的決策，優先於下方歷史提問；不是reviewer再次批准或新增實驗結果。

- **G01定位及入口已收斂**：fz1/fz2徹底不可用時使用異地fallback。第一版異地獨立hostname，使用者手動換網址即可；公司導流／災難政策後續處理，不作目前原型前置。實際hostname可達、登入、內容連結仍須驗；合成consumer可設定DR base URL，正式consumer接入未證。
- **G05以快照取捨繼續**：使用者理解非即時關係drift，認為移頁不頻繁；先沿用daily方向，4小時一次為可研究候選，不以零漂移作受控第一版前置。移頁頻率及具體風險尚未量，4小時未定案，也不是安全保證。基本Role、Space、page→media檢查仍保留。
- **資料age按成功版本量**：從來源cut時間到DR真正啟用的時間，包含產製／發布／下載延遲。同步失敗會超過排程間隔；兩fz皆失效、無法取得新來源時，更頻繁排程也不能保證取得新版。因此不得把4小時寫成災難期間漂移上限。第一版顯示實際資料時間、最後成功同步及失敗狀態。
- 下一步主線不變：獨立入口下的搜尋→pageId→既有內容／PDF→下載，以及完整發布、替換／失敗保舊與資源成本。導流政策延後、授權時效明列風險，不再反覆問已確認事項。

## 可帶去核對的第一版承諾（候選，未批准）

既有fz1／fz2路徑都無法提供所需服務時，由指定值班角色啟用異地唯讀入口。平時產製並準備最近完整、可驗證的每日版本；提供中英文title/content搜尋、Space與Tags AND、pageId閱讀及有權附件下載，顯示資料時間與限制。Web highlight可列加分項，consumer限制逐項確認。主站失效時使用最後完整版本，不依賴失效主站即時回應；恢復後由操作人核對再回切。先不要求全自動或零中斷，但須符合之後約定的恢復目標。

這不是承諾全台斷網仍可用；若故障卡包含該情境，需按其邊界驗依賴。也未限定DR只服務一小時，或批准無限期使用舊快照。
