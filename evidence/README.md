# Historical evidence

`windows-baseline-2026-11-09` contains verbatim reports/screenshots from the local synthetic Windows experiments before cloud portability changes. Includes the failed and successful ES runs. Report source hashes describe the code at that run, not necessarily the latest source. Do not edit historical reports to match later code or claim they demonstrate cloud behavior.

These reports contain synthetic fixture content and local execution metadata. New runs are written under ignored `.lab/reports`; deliberately promote only reviewed evidence into this directory.
